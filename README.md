## About
This repository showcases a comprehensive end-to-end test automation framework designed for web and API testing. 
It includes reusable utilities, reporting mechanisms, and CI readiness. Perfect for Automation Testers, QA engineers, and automation enthusiasts.

Master Branch name -> NVRaghuveer

## Features
- 🔹 **Web UI Automation** -> Selenium WebDriver 4.18
- 🔹 **Programming Language** -> Java
- 🔹 **API Testing** -> with Rest Assured
- 🔹 **TestNG** -> test orchestration and parallel execution
- 🔹 **Data-Driven Testing** -> using external files (Excel/CSV/JSON)
- 🔹 **Built-in logging** -> screenshots on failure and extensible utilities
- 🔹 **CI/CD-friendly** -> setup with Maven and config files
- 🔹 **Customizable reports** (e.g., HTML or Allure)
